# tirreno for WordPress

Improve your WP with security framework to account protection and abuse detection.

## How to use this plugin

Upload the tirreno plugin to your WordPress, activate it, then enter your `Tracking ID` and `tirreno URL`.

### tirreno console

Follow [tirreno](https://www.tirreno.com) setup [instructions](https://github.com/tirrenotechnologies/DEVELOPMENT.md).
